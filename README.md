## 📌 Sobre o Projeto
O objetivo deste sistema é ajudar os usuários a estimarem quanto um aparelho eletrodoméstico gasta de energia elétrica por mês com base em dados simples de uso diário.

## 🧮 Fórmula Utilizada
O cálculo do consumo mensal em quilowatts-hora (kWh) é feito através da seguinte fórmula:

$$\text{Consumo Mensal (kWh)} = \frac{\text{Potência (W)} \times \text{Horas/Dia} \times 30}{1000}$$

## 🚀 Como Executar o Programa
1. Certifique-se de ter o **Python 3** instalado em sua máquina.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto e execute:
   ```bash
   python app.py
   ```
